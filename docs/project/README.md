# Project Guidelines & Processes

This directory contains organizational and operational documentation for team collaboration.

## Topics Covered
- **Monorepo Workflow**: Best practices for branching, merging, and coordinating across backend, mobile, frontend, and AI teams.
- **Testing Standards**: Unit test suites, integration test suites, and mock conventions.
- **Release Management**: Versioning conventions, deployment pipelines, and environment configuration.
- **Security Policies**: Zero-secret commit policy, secure credential storage via User Secrets and environment variables.
