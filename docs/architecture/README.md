# Architecture Documentation

This folder hosts architecture documentation for the Mindora monorepo.

## Planned Documentation Roadmap
- **Overall System Architecture**: High-level interaction between Flutter App, React Doctor Dashboard, ASP.NET Core Backend, and AI inference microservices.
- **Backend Architecture**: Deep-dive into the Modular Monolith and Vertical Slice Architecture patterns used in `backend/`.
- **Data Architecture & Domain Models**: Entity-Relationship diagrams, domain state machines, soft delete, and IDOR protection policies.
- **Security Architecture**: Identity, JWT token lifecycles, role-based access control, and secure credential handling.
