# Mindora Flutter Mobile Application

This directory is reserved for the **Mindora Cross-Platform Mobile Application**.

## Overview
The Mindora mobile application provides two specialized, tailored user experiences within a single client application:

1. **Child Experience**:
   - Interactive, gamified rehabilitation activities focusing on Movement, Speech, and Attention.
   - Adaptive real-time feedback designed to fit the principle: *"The App adapts to the child, not the child adapting to the App."*
   - Intuitive, child-friendly sensory feedback.

2. **Parent Experience**:
   - Monitoring dashboard showing child progress, completed sessions, and developmental milestones.
   - Child profile management and routine scheduling.
   - Communication channel for clinical guidance and recommendations.

## Technology Stack
- **Framework**: Flutter (Dart)
- **Target Platforms**: iOS, Android
- **Backend Integration**: Consumes the Mindora ASP.NET Core Web API with JWT Bearer authentication
